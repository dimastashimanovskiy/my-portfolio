Добавить / редактировать проекты

Важно: этот сайт статический (GitHub Pages), поэтому у него нет базы данных на сервере. Проекты, которые вы добавляете здесь, сохраняются в памяти этого браузера (localStorage) и видны только вам на этом устройстве — посетители сайта их не увидят. Чтобы проекты появились у всех, нажмите «Экспортировать в config.js» внизу, скопируйте код и вставьте его в файл config.js в разделе projects, затем загрузите изменения на GitHub (commit + push).
