# Сайт-портфолио

Готовый статический сайт-портфолио на HTML/CSS/JS (без сборки, без npm — просто открыть в браузере).

## Структура файлов

```
index.html     — главная страница
admin.html     — страница для добавления проектов
config.js      — ВСЕ ваши данные: имя, навыки, проекты, отзывы, контакты
style.css      — стили
script.js      — логика сайта
assets/        — папка для ваших фото и картинок проектов
```

## Как настроить сайт под себя

1. Откройте файл **config.js** — это единственный файл, который обязательно нужно отредактировать.
2. Замените имя, роль, описание, навыки, опыт работы, ссылки на соцсети и т.д.
3. Ваше фото уже лежит в `assets/photo.jpg`, логотип — `assets/logo-icon.png` (полная версия с текстом — `assets/logo-full.png`), favicon настроен.
4. **Важно:** в `config.js` в массивах `heroSocials`, `footerSocials` и в `contact.telegramUrl` стоят placeholder-ссылки вида `https://t.me/username` — замените их на свои настоящие профили (Telegram, GitHub, Instagram, VK, Discord).
5. Картинки трёх проектов в `assets/projects/` — сгенерированные иллюстрации-заглушки. Когда будут скриншоты реальных проектов, замените файлы (сохранив те же имена или обновив пути в `config.js`) и поправьте описания/ссылки на `link`.

## Как добавлять проекты

Есть два способа:

**Способ 1 (рекомендуется) — прямо в config.js:**
Скопируйте один блок проекта в массиве `projects` и заполните поля (`title`, `category`, `description`, `tags`, `image`, `link`). Так проекты сразу видны всем посетителям сайта.

**Способ 2 — через страницу admin.html:**
Откройте `admin.html` в браузере — там есть удобная форма с загрузкой картинки. Учтите: это статический сайт без базы данных, поэтому проекты, добавленные через `admin.html`, сохраняются только в браузере вашего устройства (localStorage) и не видны другим посетителям. Чтобы сделать их видимыми всем — нажмите «Экспортировать в config.js» внизу страницы, скопируйте код и вставьте его в `config.js`, затем загрузите (закоммитьте) изменения на GitHub.

## Как опубликовать сайт на GitHub (GitHub Pages)

1. Создайте новый репозиторий на [github.com](https://github.com) (например, `my-portfolio`). Можно сделать его публичным.
2. Загрузите туда все файлы этой папки — либо через веб-интерфейс GitHub (кнопка **Add file → Upload files**, перетащите все файлы), либо через git:
   ```
   git init
   git add .
   git commit -m "Первая версия портфолио"
   git branch -M main
   git remote add origin https://github.com/ВАШ-ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
5. Branch: выберите `main`, папка `/ (root)`, нажмите **Save**.
6. Подождите 1–2 минуты — GitHub покажет ссылку вида:
   ```
   https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
   ```
   Это и есть публичный адрес вашего сайта.

Каждый раз, когда вы меняете `config.js` (например, добавляете проект) и делаете `git push` — сайт на GitHub Pages обновится автоматически в течение минуты.

## Форма обратной связи

На сайте есть настоящая рабочая форма (блок «Или напишите прямо здесь») — она отправляет письма прямо вам на почту через бесплатный сервис [FormSubmit](https://formsubmit.co), без какого-либо бэкенда. Настроено и готово к работе — эндпоинт уже указан в `config.js` → `contact.formEndpoint` (`https://formsubmit.co/ajax/dmitriyshiman2003@gmail.com`).

**Важно — разовая активация:** при самой первой отправке формы с опубликованного сайта FormSubmit пришлёт на `dmitriyshiman2003@gmail.com` письмо с просьбой подтвердить адрес (нужно один раз нажать кнопку в письме). После этого форма будет работать постоянно и все сообщения будут приходить сразу.

Если захотите сменить почту или использовать другой сервис (например, [Formspree](https://formspree.io)), просто замените ссылку в `contact.formEndpoint`.

Кнопка «Написать на email» рядом с формой работает как быстрый вариант: открывает почтовый клиент (mailto) и одновременно копирует адрес в буфer обмена — так что письмо можно отправить даже без настроенного почтового клиента на устройстве.

## Резюме (CV)

Положите PDF-файл резюме в папку `assets/` (например, `assets/cv.pdf`) и укажите путь в `config.js` → `cvLink`.
